# Multi-parcial
Técnicas multivariadas: Indicaciones
- Cada pregunta debe ser desarrollada en un determinado branch antes de mezclar todo.
- Sería bueno siempre incluir un marco teórico por pregunta, donde se va a citar el libro del profe y otros libros adicionales. 
- Se sugiere usar como agentes de AI a Claude y Google AI studio en el modo code con Gemini 3.1 como motor.
- Verificar que se maneje un lenguaje adecuado en los informes, de manera que se evite usar palabras muy específicas/técnicas a excepción de los términos vistos en clases.
