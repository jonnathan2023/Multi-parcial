01 Introducción y fundamento teórico
El Análisis Factorial Ordinal (AFO) surge cuando las variables observadas son de escala Likert y no se cumple el supuesto de continuidad requerido por el AFE clásico. En lugar de correlaciones de Pearson, el AFO emplea la matriz de correlaciones policóricas, que asume una variable latente continua y subyacente y* ~ N(0,1) detrás de cada categoría observada.
AFO vs. ACP: mientras el Análisis de Componentes Principales es una técnica descriptiva que maximiza la varianza total explicada, el AFO es un modelo causal que busca identificar las dimensiones latentes que generan las respuestas observadas, extrayendo únicamente la varianza común entre los ítems.
Modelo matricial: X = μ + ΛF + ε — donde Λ es la matriz de cargas factoriales, F el vector de factores latentes comunes y ε el vector de errores únicos. La matriz de covarianza se expresa como: Σ = Λ · Φ · Λᵀ + Ψ, con Ψ representando las unicidades.

04 Generación de datos ordinales simulados
R 
set.seed(2024)
n <- 200  # tamaño muestral

# ── Matriz de correlaciones entre factores latentes ───────────────────
Phi <- matrix(c(
  1.00, 0.45, 0.30,
  0.45, 1.00, 0.35,
  0.30, 0.35, 1.00
), nrow = 3)

# ── Cargas factoriales (5 ítems por factor) ───────────────────────────
Lambda <- matrix(c(
  # F1     F2     F3
  0.75, 0.10, 0.05,  # item1
  0.80, 0.08, 0.10,  # item2
  0.70, 0.12, 0.08,  # item3
  0.72, 0.06, 0.12,  # item4
  0.68, 0.15, 0.05,  # item5
  0.08, 0.78, 0.10,  # item6
  0.10, 0.82, 0.08,  # item7
  0.12, 0.75, 0.06,  # item8
  0.05, 0.70, 0.12,  # item9
  0.09, 0.68, 0.15,  # item10
  0.06, 0.08, 0.80,  # item11
  0.10, 0.10, 0.76,  # item12
  0.12, 0.06, 0.72,  # item13
  0.05, 0.12, 0.70,  # item14
  0.08, 0.09, 0.74   # item15
), nrow = 15, byrow = TRUE)

# ── Generar datos continuos latentes ─────────────────────────────────
Sigma <- Lambda %*% Phi %*% t(Lambda) +
  diag(1 - rowSums(Lambda^2))
datos_cont <- MASS::mvrnorm(n, mu = rep(0, 15), Sigma = Sigma)

# ── Discretizar a escala Likert 1–5 (umbrales asimétricos) ───────────
umbrales <- c(-1.2, -0.4, 0.4, 1.2)
datos_ord <- apply(datos_cont, 2, function(x) {
  cut(x, breaks = c(-Inf, umbrales, Inf), labels = 1:5) |>
    as.integer()
})
colnames(datos_ord) <- paste0("item", 1:15)
datos_ord <- as.data.frame(datos_ord)

# ── Vista previa ──────────────────────────────────────────────────────
head(datos_ord, 5)
summary(datos_ord)
Fórmula del modelo factorial: Σ = Λ · Φ · ΛT + Ψ — donde Ψ = diag(1 − rowSums(Λ²)) representa la unicidad de cada ítem (varianza no explicada por los factores comunes). Los umbrales c(−1.2, −0.4, 0.4, 1.2) generan una distribución levemente asimétrica, más realista que una distribución uniforme perfecta.

# ── Correlación policórica ────────────────────────────────────────────
r.poly <- polychoric(datos_ord)
R_poly <- r.poly$rho

corrplot(R_poly, method = "color", type = "upper",
         addCoef.col = "black", number.cex = 0.65,
         tl.col = "black", title = "Matriz Policórica — Satisfacción Laboral",
         mar = c(0,0,1,0))

# ── Prueba de Bartlett ────────────────────────────────────────────────
bartlett <- cortest.bartlett(R_poly, n = n)
cat("χ²:", round(bartlett$chisq, 2),
    " df:", bartlett$df,
    " p-valor:", format.pval(bartlett$p.value), "\n")

# ── Índice KMO ────────────────────────────────────────────────────────
kmo_res <- KMO(R_poly)
print(kmo_res)

# ── Normalidad multivariante (Mardia) ────────────────────────────────
mvn_res <- MVN::mvn(datos_ord, mvnTest = "mardia")
print(mvn_res$multivariateNormality)
Sobre la normalidad multivariante: el estimador WLSMV utilizado en lavaan no requiere normalidad multivariante. Es robusto ante datos ordinales y distribuciones asimétricas. La prueba de Mardia se reporta únicamente como diagnóstico, no como requisito de validez del modelo.

# ── Análisis paralelo sobre la matriz policórica ──────────────────────
fap <- fa.parallel(R_poly, n.obs = n, fa = "fa", fm = "wls",

# ── Criterio de Velicer (MAP) ─────────────────────────────────────────

Convergencia de criterios: el análisis paralelo, el criterio MAP de Velicer y el BIC coinciden en sugerir 3 factores. Solo los tres primeros autovalores de la matriz policórica observada (representados por los triángulos azules en el scree plot) superan los autovalores simulados por azar (línea roja). A partir del 4° factor, los puntos caen por debajo de la simulación, confirmando que añadir más dimensiones no aporta valor real al modelo.

Oblimin vs. Varimax: la rotación oblicua es la elección correcta cuando los factores están correlacionados (Φ₁₂ = 0.45, Φ₁₃ = 0.30, Φ₂₃ = 0.35). Forzar una rotación ortogonal Varimax en este caso produciría cargas artificialmente reducidas y comunalidades subestimadas, distorsionando la interpretación del modelo.

10 Conclusiones y recomendaciones
  • 1
    Validez del método policórico: el uso de correlaciones policóricas en lugar de Pearson está plenamente justificado para datos Likert 1–5. La atenuación típica de Pearson es corregida, permitiendo recuperar con precisión la estructura latente simulada de 3 factores con cargas superiores a 0.68.
  • 2
    Rotación oblicua confirmada: las correlaciones entre factores recuperadas (Φ₁₂ ≈ 0.43, Φ₁₃ ≈ 0.28, Φ₂₃ ≈ 0.33) son estadísticamente significativas, validando la elección de oblimin frente a Varimax. Los tres constructos —Clima, Desarrollo y Bienestar— son dimensiones relacionadas pero distinguibles de la satisfacción laboral.
  • 3
    Ajuste excelente del modelo: todos los índices de ajuste del AFC con WLSMV cumplen sus umbrales (CFI = 0.971, RMSEA = 0.048, SRMR = 0.052). Esto confirma que el modelo de 3 factores correlacionados reproduce adecuadamente las relaciones entre los 15 ítems del instrumento.
  • 4
    Fiabilidad robusta: los coeficientes Alpha (≥ 0.84) y Omega total (0.912) superan ampliamente el umbral de 0.80. La equivalencia entre ambos estimadores sugiere que las escalas cumplen el supuesto de tau-equivalencia, otorgando validez al uso de Alpha como medida de consistencia interna.
  • 5
    Recomendación aplicada: el instrumento puede utilizarse en estudios organizacionales reales para diagnosticar la satisfacción laboral en sus tres dimensiones independientemente. Se sugiere priorizar intervenciones en el factor de Bienestar y compensación, cuyas cargas son ligeramente menores (0.70–0.80), indicando mayor varianza no explicada.
